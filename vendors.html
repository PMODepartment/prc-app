How to use this grid — works like Excel
Select — click a cell, drag for a range, Shift+click or Shift+arrows to extend, Ctrl+A for everything.
Edit — just start typing, or Enter / F2. Esc cancels.
Move — arrows, Tab, Enter. Add Ctrl to jump to the edge of the data.
Fill — drag the small red corner handle down, or Ctrl+D to fill down from the top of the range.
Copy / paste — Ctrl+C / Ctrl+V, round-trips with real Excel. Del clears a range.
Undo — Ctrl+Z. Nothing reaches the database until you press Save changes.
Columns — drag a header edge to resize (double-click resets), click the pin to freeze up to that column, click the section band to hide a whole group, and use the caret to set one value on every visible row.

Vendor Registrations

People who registered from the public link and are waiting to be given access to their company’s profile. Check what they submitted against the vendor record, then approve or decline.

Add a Vendor
Add a vendor to the directory — fill in what you know now, invite them to self-manage their profile later if needed.
Merge Vendors
Fold duplicate records (typos / different names for one company) into a single canonical vendor. All their products, certifications, personnel, rates, bids and linked work packages move to the one you keep; the duplicates are then deleted. Garbled entries that look like SEVERAL company names joined together are handled by the separate Split tool instead — they never appear here as a suggested duplicate.
Suggested Duplicate Groups
Auto-detected by comparing vendor names — review each group, then merge or uncheck any entry that doesn't actually belong. "Merge All Groups" processes every group at once using whatever canonical/checked selections are currently shown.
Manual Merge (advanced)
Didn't see a duplicate above? Search and pick it yourself.
Remove Exact Duplicates
Vendors whose names are identical after ignoring case and extra spaces. One record is kept per name and the rest are folded into it — products, certifications, personnel, rates, bid history, work-package links and trade categories all move to the record that is kept, so nothing is lost.

Split Garbled Vendor Names
These vendor records look like several company names joined together (comma, slash, colon, or just run together with a repeating "Inc./Corp." suffix). Review the segments below, fix them if needed, then split each into separate vendor records — a segment that already matches an existing vendor links to it instead of creating a duplicate. Records with no delimiter aren't auto-flagged — use the search below to pull one in and split it manually.
