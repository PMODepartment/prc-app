Import from Excel Monitoring Sheet

Reads a Work-Package Monitoring .xlsx directly (no CSV step) and replaces a project's work packages. Columns are matched by their header names, so it adapts to each project's sheet layout automatically.

Checking access…

1 · Choose file & project

Import rules applied:
• Award status — taken from the sheet's own Remarks / Status column ("Awarded" / "Not yet Awarded"). A work package that carries a provisional cost but is flagged Not yet Awarded stays Not Yet Awarded (the cost is still imported, but it can't inflate the awarded total or the savings).
• Advance award dates — a WP whose actual award date is in the future is imported as Not Yet Awarded (the advance date is ignored until it arrives).
• OSM — every WP is No unless its Remarks mention "OSM".
• Charging — every WP is set to Main Contract.
